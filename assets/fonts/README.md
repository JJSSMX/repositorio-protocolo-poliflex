# Repositorio Controlado de Tipografías (/assets/fonts)

Este directorio está reservado como la fuente canónica de tipografías locales del proyecto *Protocolo Familiar POLIFLEX*.

## Política de Uso
1. **Sin sustituciones silenciosas**: Para la compilación editorial definitiva, Typst utilizará `--font-path ./assets/fonts` para cargar las familias tipográficas oficiales sin depender de fuentes del sistema operativo.
2. **Estado actual (Fase 3.1)**: Directorio preparado. No se han descargado ni seleccionado tipografías definitivas por cuenta propia. Las tipografías definitivas serán proporcionadas o aprobadas formalmente por el cliente en las fases subsiguientes.
